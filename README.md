# Мастер-класс «Создай свою игру за один день»

Рабочий стандарт для небольших браузерных игр, создаваемых в ChatGPT без API и платной инфраструктуры. Мастер-класс намечен на 7 ноября 2026 года.

## Файлы
- [GAME_STANDARD.md](GAME_STANDARD.md) — обязательный минимум качества каждой игры.
- [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md) — готовый текст для инструкций проекта ChatGPT.
- [QA_CHECKLIST.md](QA_CHECKLIST.md) — практическая приёмка перед выдачей участнику.
- [templates/input.js](templates/input.js) — пример нормализации клавиатуры, не зависящий от русской/английской раскладки. При выпуске автономного HTML встраивать содержимое файла в его `<script>`, не подключать внешним URL.
- [tests/input.test.cjs](tests/input.test.cjs) — тесты этой функции; запуск `node --test tests/input.test.cjs` (Node требуется только для разработчика, не для участников).

## Как применять
1. Скопировать содержимое PROJECT_INSTRUCTIONS.md в инструкции ChatGPT-проекта.
2. Перед генерацией каждого проекта предоставить модели GAME_STANDARD.md или вставить ключевые правила в промпт. Само наличие файла на GitHub не означает, что любой чат его прочитал.
3. После генерации запустить QA_CHECKLIST.md на реально выданном HTML-файле.
4. После любой правки повторить проверки новой функции и старого управления.
5. Сохранять последнюю рабочую версию HTML вне чата; не заменять её, пока новую версию не проверили.

Этот репозиторий содержит требования и образец ввода, **не** доказательство того, что игры автоматически прошли тесты. Не публиковать приватные анкеты участников.
